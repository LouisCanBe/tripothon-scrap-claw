记忆 / 现实 对照原则

同一剪影对应两件模型：一套「食物/记忆」，一套「垃圾/现实」。平面缩略图要几乎一样，立体才分出真假。

推荐管线（在 Tripo 页操作）

  1. 出共用剪影（侧视或 45°，纯色底，只锁外轮廓）。
  2. 先做记忆版四视图 → 四视图 → 模型 → 验收剪影。
  3. 再做现实版四视图：构图与剪影对齐，只改材质/腐烂/锈迹 → 再跑四视图生成。
  4. 若拓扑已锁死：记忆版 GLB → 重新贴图 / 图生贴图，比重做网格省积分。
